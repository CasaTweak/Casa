# Casa

Download the latest version: **[Casa.zip](https://github.com/CasaTweak/Casa/releases/latest/download/Casa.zip)**

1. Extract `Casa.zip` and run `Casa.exe`.
2. Click **Sign in with Discord** (the account you bought with), or enter your code.

Windows 10 / 11 (64-bit). Internet is needed once for activation.

---

حمّل آخر نسخة من الرابط فوق، فك الضغط وشغّل `Casa.exe`، واضغط «سجّل بالديسكورد» بنفس الحساب اللي اشتريت فيه، أو حط الكود.
